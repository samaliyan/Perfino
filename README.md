# قیمت عطر

برنامه‌ی اندروید خیلی سبک برای مغازه‌ی عطرفروشی: فهرست الفبایی عطرها با یک قیمت امروز.

## ساخت فایل APK (بدون Android Studio)

1. این پوشه را در یک مخزن (repository) خالی گیت‌هاب بارگذاری کن.
2. در گیت‌هاب برو به تب Actions.
3. روی «Build APK» کلیک کن و گزینه‌ی «Run workflow» را بزن.
4. بعد از حدود ۵ دقیقه، همان صفحه را باز کن و از پایین صفحه فایل «PerfumePrice-apk» را دانلود کن.
5. داخل آن فایل app-debug.apk است؛ آن را روی گوشی نصب کن.

## ساخت با Android Studio

1. Android Studio را باز کن و گزینه‌ی Open را بزن.
2. همین پوشه را انتخاب کن.
3. صبر کن Gradle همگام شود.
4. از منوی Build گزینه‌ی Build APK را بزن.

## اگر یک سایت ساختارش عوض شد

کل منطق خواندن سایت‌ها در این فایل است:

```
app/src/main/assets/www/core.js
```

بخش `SOURCES` در انتهای فایل فهرست سایت‌هاست.
در برنامه: دکمه‌ی تنظیمات (چرخ‌دنده)، سپس «کپی گزارش خطا» را بزن و متن را برای سازنده بفرست.

## تست‌ها

پوشه‌ی tests شامل تست‌های خودکار است (نیاز به Playwright و Python دارد):

```
node tests/gen.js
python3 tests/t1_data.py
python3 tests/t3_flow.py
python3 tests/t13_hier.py   # چیدمان برند/مدل/جزئیات در ۲۴ حالت
python3 tests/t15_gate.py   # قفل ورود
python3 tests/t16_taps.py   # لمس واقعی
node tests/t14_lil.js       # خواندن لیلیوم
node tests/t5_titles.js
```

## نسخه ۱.۱
- نام و عکس عطرها یک‌بار ذخیره می‌شود؛ بروزرسانی ۱۵ دقیقه‌ای فقط قیمت‌ها را عوض می‌کند.
- دریافت اولیه فقط بار اول (یا هنگام دیده‌شدن محصول تازه) انجام می‌شود.

## نسخه ۱.۲
- جنسیت (مردانه/زنانه/یونیسکس) جزو هویت عطر است؛ دو نسخه‌ی یک عطر هرگز یکی نمی‌شوند.
- نام‌هایی که فقط «تقریباً» شبیه‌اند، فقط وقتی یکی می‌شوند که قیمتشان هم جور باشد. موردهای مبهم نشان داده نمی‌شود.
- اگر سایتی دو قیمت (قدیم و جدید) بنویسد، قیمت با تخفیف خوانده می‌شود.

## نسخه ۱.۳
- لیلیوم: اندازه (۱۰۰ میل و ...) در اسم محصول نیست و فقط در جدول مشخصات است؛ حالا از همان جدول (و دسته‌بندی) خوانده می‌شود. جنسیت و نوع عطر هم از همان‌جا.
- صفحه‌ی اول فهرست برندهاست؛ با زدن روی برند، اسم عطرهای آن برند می‌آید؛ با زدن روی عطر، مردانه/زنانه و اندازه‌ها با قیمت می‌آید.
- زدن روی عکس، عکس بزرگ را نشان می‌دهد.
- بار اول تا دانلود کامل (فهرست، قیمت و عکس‌ها) وارد برنامه نمی‌شود؛ پیشرفت نشان داده می‌شود.
- پنج بار زدن روی «نسخه» پایین تنظیمات، دکمه‌های «دریافت کامل از اول» و «کپی گزارش» را نشان می‌دهد (برای سازنده).

## نسخه ۱.۴ (نصب و آپدیت)
- برنامه حالا با یک کلید امضای ثابت ساخته می‌شود (فایل `app/perfume.keystore`). پس از یک‌بار نصب، نسخه‌های بعدی روی آن نصب می‌شوند و خطای «conflict» نمی‌دهند. این فایل را پاک نکنید.
- نسخه‌ی ساخته‌شده حالت release است (قابل اشکال‌زدایی نیست) و شماره‌ی نسخه با هر ساخت بالا می‌رود.

## نسخه ۱.۵
- در تنظیمات، بخش «برندها»: هر برند را می‌شود خاموش کرد؛ برند خاموش در فهرست دیده نمی‌شود و عکسش دانلود نمی‌شود.
